# Surgical Management System 🏥

A full-stack hospital management system to streamline surgical operations.

## Features
- Surgery scheduling & theatre availability
- Patient records management
- Surgeon assignment & role-based access (Admin, Doctor, Nurse)
- Real-time dashboard

## Tech Stack
React, Node.js, Express, MongoDB, JWT Auth

## Status
Currently building - Final Year Project at Pentecost University, Expected June 2026
